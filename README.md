# Student Database Application System – Backend

A backend-based Student Database Application System developed using FastAPI, CRUD operations, ChromaDB, LangGraph, and Gemini API integration.

## Features

- Student CRUD operations
- FastAPI backend
- Swagger API documentation
- SQLite database
- ChromaDB vector database
- AI student assistant
- LangGraph-based chatbot workflow
- Gemini API integration
- Frontend interface
- Docker support

## Technologies Used

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- ChromaDB
- LangGraph
- Gemini API
- HTML
- CSS
- JavaScript
- Docker
